### Что входит в эту версию

#### Бот (aria/)
- **Multi-tenant**: один процесс запускает несколько ботов из БД
- **Мастер записи**: категория → услуга → дата → время → имя клиента
  - Занятые слоты скрыты из выбора времени
  - Цена и длительность услуги в подтверждении
- **Дашборд** с переключением период (📅 День / 📆 Неделя / 🗓 Месяц)
  - Ближайшая запись + обратный отсчёт (ч мин)
  - Свободные окна на день
  - Доходы: ожидается / оплачено / доля мастера % / чистыми после налога
- **📋 Ближайшие**: группировка по датам с заголовками, тап → карточка
- **Карточка записи**: 💰 Оплата · ✏️ Перенос · 📝 Заметка · ❌ Отмена · ◀️ Назад к списку
- **Кнопки reply-клавиатуры** (Сегодня/Завтра/Дашборд/Ближайшие/Новая запись) работают из любого состояния FSM
- **Каталог услуг**: категории + позиции с ценой и длительностью (редактирование инлайн)
- **Настройки владельца**: % мастера, % налога — через инлайн-меню
- **Google Calendar** интеграция (опционально)
- **Email-мониторинг** (опционально)
- **Graceful SIGTERM shutdown** — Railway не ловит конфликты при деплое

#### Деплой
- **Платформа**: Railway
- **Procfile**: `worker: python -m aria.main` + `web: gunicorn server:app`
- **БД**: PostgreSQL (asyncpg, схема накатывается автоматически при старте)
- **Переменные**: `ARIA_BOT_TOKEN`, `ANTHROPIC_API_KEY`, `DATABASE_URL`

#### Стек
- Python 3.11
- aiogram 3.x (long polling)
- asyncpg + PostgreSQL
- Anthropic Claude API
- APScheduler
- Flask + Gunicorn (web-часть)
